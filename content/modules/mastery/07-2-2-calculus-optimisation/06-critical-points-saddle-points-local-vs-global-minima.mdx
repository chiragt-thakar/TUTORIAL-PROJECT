A critical point is where the gradient vanishes. It is the first-order necessary condition for a
local extremum, but it does not distinguish a bottom from a top from a saddle — the Hessian does
that.

The useful reframing for deep learning is that a small gradient does not imply a minimum. Saddles,
nearly flat directions, ill-conditioning, and genuine local minima can all occur. High dimension
provides many possible negative-curvature directions, so saddles are common in several theoretical
models and empirical loss landscapes.

It does **not** prove that almost every critical point of an
arbitrary deep network is a saddle, or that bad local minima cannot exist.

<TypeScriptComparison>

- Checking `∇f ≈ 0` in TypeScript is `norm(grad) < tol` — but a small gradient norm alone does not tell you it is a minimum; saddles have zero gradient too.
- A positive smallest Hessian eigenvalue at a stationary point is sufficient for a strict local minimum; a zero value is inconclusive. Lanczos on Hessian–vector products supplies numerical evidence, not a proof without residual and regularity bounds.
- Sampling random symmetric matrices shows that positive definiteness becomes rare in that matrix ensemble. It illustrates the geometry, but it does not sample Hessians conditioned on being critical points of a neural-network loss.
- Newton's method converges to *any* stationary point; a TS or Python Newton loop can happily land on a saddle unless you add negative-curvature handling.

</TypeScriptComparison>

## First- and second-order conditions

A point `x*` is **critical** (stationary) when `∇f(x*) = 0`. This is necessary for a local minimum
or maximum but not sufficient. The second-order test uses `H = ∇²f(x*)`:

- `H` positive definite → strict local **minimum**.
- `H` negative definite → strict local **maximum**.
- `H` indefinite → **saddle** (up in some directions, down in others).
- `H` positive semidefinite and singular → **inconclusive**; a zero eigenvalue means higher-order
  terms decide along that direction.

```python
import numpy as np

def classify(H, tol=1e-10):
    w = np.linalg.eigvalsh(0.5 * (H + H.T))
    if w.min() > tol:  return "min"
    if w.max() < -tol: return "max"
    if w.min() < -tol < tol < w.max(): return "saddle"
    return "degenerate"

assert classify(np.array([[2.0, 0.0], [0.0, -3.0]])) == "saddle"
```

## Local versus global

A local minimum is a point that beats its neighbourhood. A **global** minimum beats everything. A
smooth non-convex function can have many local minima, and broad classes of globally optimising
non-convex functions are computationally hard. There is no universal first- or second-order test
that turns an arbitrary local minimum into a certified global one.

Globality follows only from extra structure: **convexity** (every local minimum is global), or a
**Polyak–Łojasiewicz / gradient-dominance** condition (`½||∇f||² ≥ μ(f − f*)`), or exhaustive
enumeration for a discrete problem. Typical deep-net losses are not globally convex and usually have
no known global PL guarantee. Training success is empirical and architecture/problem dependent.

```python
# f(x) = x**4 - 3x**2 + x : two local minima, one global
xs = np.linspace(-2, 2, 1000)
f = xs**4 - 3*xs**2 + xs
# both minima have f' = 0 and f'' > 0; only one has the lower value
```

<Concept>

`∇f = 0` is cheap to check and tells you almost nothing on its own. `λ_min(H) > 0` is sufficient for
a strict local minimum; `λ_min(H) = 0` needs higher-order or problem-specific analysis. To establish
a *global* minimum you need global structure such as convexity or a proof specific to the problem.

</Concept>

## Why saddles are often prominent in high dimensions

As an intuition model, draw a symmetric matrix from an ensemble whose eigenvalue distribution spans
both signs. As dimension grows, requiring every eigenvalue to be positive is increasingly
restrictive, while one negative eigenvalue is enough for a saddle. This explains why high dimension
can make indefinite curvature easy to encounter.

But the eigenvalue signs are correlated, and a Hessian sampled **at a critical point** is not a
generic random symmetric matrix. Its distribution depends on the objective, data, parameterisation,
regularisation, and loss level. Some random-landscape models predict that high-loss critical points
have more negative directions and low-loss critical points are more likely to be minima. Empirical
neural-network Hessians often show many near-zero directions and, away from convergence, negative
curvature.

These are conditional theoretical and empirical observations—not a universal counting
theorem for all deep networks.

```python
rng = np.random.default_rng(0)
def frac_minima(n, trials=2000):
    c = 0
    for _ in range(trials):
        A = rng.standard_normal((n, n)); A = 0.5 * (A + A.T)
        if np.linalg.eigvalsh(A).min() > 0: c += 1
    return c / trials

fractions = [frac_minima(n) for n in (2, 6, 12)]
assert fractions[0] > fractions[-1]   # illustration for this ensemble, not a proof about losses
```

## Escaping saddles

A **strict saddle** has `λ_min(H) < 0` — a direction of strict negative curvature. Under smoothness
and strict-saddle assumptions, perturbed gradient descent can escape by adding an appropriately
scaled random kick when the gradient is tiny. SGD noise can help when its covariance has a component
along the escape direction, but mini-batch noise may be anisotropic, too small, or even vanish, so it
is not an automatic perturbation guarantee.

The cost is time on the **plateau**: near a saddle the gradient is small in every direction, so
progress crawls until the negative-curvature direction is found. Momentum helps by accumulating
velocity through the flat region; a well-scaled learning rate helps by not wasting the small gradient
signal.

```python
def perturbed_gd_step(x, grad_f, eta, noise_scale=1e-3, grad_tol=1e-4, rng=None):
    rng = np.random.default_rng() if rng is None else rng
    g = grad_f(x)
    if np.linalg.norm(g) < grad_tol:                  # near a critical point
        direction = rng.standard_normal(x.shape)
        direction /= np.linalg.norm(direction) + 1e-12
        x = x + noise_scale * direction
        g = grad_f(x)
    return x - eta * g
```

## Degenerate minima and manifolds of minima

Not every minimum is an isolated point. Continuous parameter symmetries can create a *manifold* (or
orbit) of equivalent parameter settings with the same function and loss. At a smooth local minimum,
the Hessian is positive semidefinite; tangent directions generated by a continuous symmetry are
zero-curvature directions, so that minimum is not strict. Over-parameterisation often adds many
nearly flat directions, but it does not guarantee that every low-loss solution belongs to one
connected manifold.

Symmetries multiply optima: permuting hidden units, or rescaling a ReLU layer up and a following one
down, gives a different parameter vector with the *same* function and loss. So deep nets have a
combinatorially large set of equivalent global minima, and after accounting for symmetry many of them
are connected by low-loss paths (mode connectivity).

## Doing this in floating point

A small gradient norm is an ambiguous stopping criterion: it is small at minima, maxima, and
saddles, and near-zero across a whole plateau. For numerical second-order evidence, estimate
`λ_min(H)` with Lanczos on Hessian–vector products and inspect the Ritz residual. A clearly negative
value exposes negative curvature; a near-zero estimate leaves the test inconclusive. A positive
estimate is a rigorous certificate only with suitable approximation-error and neighbourhood bounds.

Newton's method drives `∇f` to zero, so it converges to *whichever* stationary point is nearby — a
saddle included. With zero modes regularised, replacing `H` by `|H|` makes `-|H|^{-1}g` a descent
direction when `g` is nonzero. Trust-region methods can instead detect and exploit negative curvature.

```python
# certify: lambda_min via a few HVP inverse-iteration or Lanczos steps
def second_order_evidence(grad, smallest_ritz_value, grad_tol=1e-6, curvature_tol=1e-5):
    """Numerical evidence, not a formal certificate between sampled points."""
    return np.linalg.norm(grad) <= grad_tol and smallest_ritz_value > curvature_tol
```

<ProductionNote>

Do not stop training on gradient norm alone. If progress stalls with a small gradient, estimate
bottom curvature: a reliably negative Ritz value is evidence of a descent direction, while a value
near zero leaves the second-order test inconclusive. A positive estimate plus a small gradient is
local numerical evidence only; rigorous certification also needs error bounds and neighbourhood
regularity.

On a saddle, an explicit perturbation, a negative-curvature step, or a trust-region
method may help. Do not assume ordinary SGD noise or more momentum will always escape it.

</ProductionNote>

## Cost

Checking `∇f = 0` is one gradient. Classifying via a dense Hessian eigendecomposition is `O(n³)` and
infeasible at scale; certifying via `λ_min` from Lanczos is a handful of HVPs. Escaping a saddle
with perturbed GD adds one random draw and continues; the dominant cost is the extra iterations
spent on the plateau, which momentum and noise reduce.

## Exercises

<Exercise id="lcp-classify-2d" difficulty="easy">

Find the critical points of `f(x, y) = x^3 - 3x + y^2` and classify each with the Hessian.

<Solution>

`∇f = (3x^2 - 3, 2y)`. Set to zero: `2y = 0` gives `y = 0`; `3x^2 - 3 = 0` gives `x = ±1`. Critical
points `(1, 0)` and `(-1, 0)`.

`H = [[6x, 0], [0, 2]]`.

At `(1, 0)`: `H = [[6, 0], [0, 2]]`, both eigenvalues positive → **local minimum**, `f = 1 - 3 + 0
= -2`.

At `(-1, 0)`: `H = [[-6, 0], [0, 2]]`, eigenvalues `-6` and `2`, mixed signs → **saddle point**,
`f = -1 + 3 + 0 = 2`.

Neither is a global minimum: `f -> -infinity` as `x -> -infinity`, so `f` is unbounded below and has
no global minimum.

</Solution>
</Exercise>

<Exercise id="lcp-monkey-saddle" difficulty="medium">

For `f(x, y) = x^3 - 3x y^2` (the "monkey saddle"), show that the origin is a critical point where
the second-order test is inconclusive, and describe the shape.

<Solution>

`∇f = (3x^2 - 3y^2, -6xy)`. At `(0, 0)` this is `(0, 0)`, so the origin is critical.

`H = [[6x, -6y], [-6y, -6x]]`. At `(0, 0)`, `H = [[0, 0], [0, 0]]` — the zero matrix. Both
eigenvalues are `0`, so the second-order test says nothing.

The shape is decided by the cubic terms. Along `y = 0`, `f = x^3` (up for `x > 0`, down for
`x < 0`). In polar coordinates `f = r^3 cos(3θ)`, which oscillates between positive and negative
three times around the origin — three "up" ridges and three "down" valleys meeting at the origin
(hence "monkey saddle": room for two legs and a tail). It is neither a min, a max, nor an ordinary
two-way saddle.

</Solution>
</Exercise>

<Exercise id="lcp-saddle-fraction" difficulty="hard">

Use a random-matrix model to explain why positive-definite Hessians can become rare with dimension.
Then state why this toy model does not determine the fraction or loss level of minima in an arbitrary
neural network.

<Solution>

As a toy model, draw a random symmetric matrix whose eigenvalue distribution is roughly symmetric
about zero (for example, a scaled Gaussian orthogonal ensemble). The simplest sign-counting
intuition treats each eigenvalue as positive with probability roughly `p`, although real random
matrix eigenvalues are correlated.

A critical point is a local minimum only if *all* `n` eigenvalues are positive. Treating them as
approximately independent, that probability is about `p^n`, which decays exponentially in `n`.
This conclusion belongs to the assumed ensemble. It does not count Hessians of a particular loss,
because conditioning on `grad f = 0` changes their distribution.

Some random-landscape models additionally tie a spectral shift to loss level, producing more
negative directions at high loss and more minima at low loss. That is a model-specific result to
check against a real objective, not a proof that gradient-following training must reach low loss.

</Solution>
</Exercise>

<Exercise id="lcp-interview-local-minima" difficulty="interview">

In an interview: "Do deep networks get stuck in bad local minima? What actually makes their
optimisation hard?"

<Solution>

I would not claim that bad local minima are impossible. Theory for some structured or random
objectives and empirical Hessian studies show that **saddles** and nearly flat directions can be
important in high-dimensional models. Continuous symmetries and over-parameterisation can also
create equivalent or connected low-loss solutions. These findings depend on architecture, data,
objective, and training regime; they are not a universal landscape theorem.

So the hard parts are: (1) **saddle plateaus** — the gradient is tiny in every direction and progress
crawls until a negative-curvature escape direction is found; (2) **ill-conditioning** — a wide
spread of Hessian eigenvalues forcing a small learning rate and zig-zagging.

Other difficulties include (3)
**vanishing/exploding gradients** from the product of layer Jacobians; (4) the **stochastic**
gradient, whose noise can help when it excites a negative-curvature direction but also hurts (variance slows the final
approach).

Mitigations map onto these: momentum and adaptive methods carry velocity through plateaus and act as
preconditioners; normalisation and residual connections tame conditioning and the Jacobian product;
warmup respects early large curvature; and second-order or negative-curvature-aware methods
(saddle-free Newton, trust region) explicitly handle saddles. The practical stopping test is not
"gradient norm small" — that is true at saddles too — but a plateau in the loss on a held-out
metric.

</Solution>
</Exercise>

<Exercise id="lcp-plateau-real-world" difficulty="real-world">

Training loss stops improving for thousands of steps, then suddenly drops again. The gradient norm
during the plateau is small but nonzero. Diagnose and decide whether to intervene.

<Solution>

The sudden resumption after a long flat stretch is the signature of a **saddle plateau**: the
optimiser spent those steps in a region of small gradient and near-zero curvature in most
directions, slowly aligning with a negative-curvature escape direction, and once it left the flat
centre the loss fell again.

Confirm it. Estimate `λ_min(H)` with ~30 Lanczos iterations on Hessian–vector products at a plateau
checkpoint: a clearly negative value confirms a strict saddle; `λ_min ≈ 0` with a persistent tiny
gradient suggests a degenerate flat region instead. Also log per-direction curvature and the angle
between successive update directions — on a plateau the updates are small and slowly rotating.

Decide. If the loss eventually drops on its own and total budget allows, no intervention is needed;
plateaus are normal.

If they eat too much budget: increase momentum (β toward 0.95–0.99) so velocity carries through the
flat region; raise the learning rate within the stable range; add a small parameter perturbation
when the gradient norm is below a threshold; or take a few negative-curvature steps along the
Lanczos-estimated smallest eigenvector.

Do not simply lower the learning rate — that lengthens the plateau. Re-measure `λ_min` and the loss
slope after any change.

</Solution>
</Exercise>

## Gotchas

<Gotchas>

<Gotcha question="The gradient norm is tiny, so I've converged to a minimum.">

Or a maximum, or a saddle, or you are on a plateau. `∇f = 0` is necessary for all critical points.
Check `λ_min(H)` (via Lanczos on HVPs) before claiming a minimum.

</Gotcha>

<Gotcha question="Deep networks get stuck in bad local minima.">

Rarely. In high dimensions the critical points a gradient method meets are almost all saddles, and
the local minima that exist are typically at low loss. The obstacles are saddle plateaus and
conditioning, not bad wells.

</Gotcha>

<Gotcha question="Newton's method will find the minimum from anywhere.">

Newton drives `∇f` to zero, so it converges to the nearest *stationary* point — which can be a
saddle or a maximum. Use saddle-free Newton (`|H|`), a trust region, or negative-curvature steps.

</Gotcha>

<Gotcha question="A zero Hessian eigenvalue at a critical point means it's a minimum along that direction.">

It means the second-order test is silent along that direction. The monkey saddle `x³ − 3xy²` has a
zero Hessian at the origin and is not a minimum in any direction.

</Gotcha>

<Gotcha question="I found two solutions with different weights, so the model has two different local optima.">

Check for symmetry first. Permuting hidden units or rescaling successive layers gives different
parameter vectors that compute the *same* function with the *same* loss. They are the same optimum
up to symmetry.

</Gotcha>

</Gotchas>

## Summary

A critical point has `∇f = 0`; the Hessian's eigenvalue signs classify it as a minimum (all
positive), a maximum (all negative), a saddle (mixed), or degenerate (a zero eigenvalue). A local
minimum is not automatically global — that needs convexity, a PL condition, or a problem-specific
argument.

High dimension makes all-positive curvature restrictive in broad random-matrix models, and many
studied or observed non-convex landscapes contain saddle and nearly flat directions. That intuition
does not establish the fraction of saddles in an arbitrary neural-network loss. Under explicit
smoothness, strict-saddle, and perturbation assumptions, noisy first-order methods can escape strict
saddles; ordinary SGD noise may help but is not guaranteed to have the needed direction or scale.

Deep-net optima need not be isolated: continuous rescaling symmetries can produce manifolds, while
permutation symmetries produce discrete families of equivalent solutions. Use a small gradient plus
a bottom-curvature estimate as numerical evidence, not an unconditional certificate. The Practice,
Debug, Interview, Test, Project, and Review tabs build the classification, the saddle experiments,
and the escape strategies.
