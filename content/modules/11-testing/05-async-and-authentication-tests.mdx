## Async tests await real async boundaries

With an async test plugin, mark or configure async tests and use HTTPX's ASGI transport:

```python
@pytest.mark.anyio
async def test_list_tasks(app):
    transport = httpx.ASGITransport(app=app)
    async with httpx.AsyncClient(transport=transport, base_url="http://test") as client:
        response = await client.get("/tasks")
    assert response.status_code == 200
```

## Authentication and authorization are different suites

Authentication cases include missing, malformed, expired, incorrectly signed, and valid tokens. Authorization cases combine identity, resource relationship, action, and expected result.

```python
@pytest.mark.parametrize(("role", "owner", "status"), [
    ("admin", False, 204),
    ("member", True, 204),
    ("member", False, 403),
])
async def test_delete_project_permissions(role, owner, status): ...
```

Do not test only happy paths or encode roles directly into route-test setup everywhere. Central fixtures can mint tokens, but assertions should still reveal the permission rule.

## Production note

Use deliberately short-lived tokens with a fixed clock in expiry tests. Never place real secrets or production signing keys in test configuration.
