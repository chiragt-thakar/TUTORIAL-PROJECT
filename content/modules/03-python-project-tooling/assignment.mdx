## Scenario

Your typed task domain must become a repository another engineer can clone, validate, and extend without guessing which Python or commands you used.

<Assignment id="tooling-assignment-work">

## Requirements

Turn the Module 2 code into an installable uv project using Python 3.13, a src layout, a committed lockfile, Ruff, strict mypy or pyright, pytest, and pre-commit. Add safe environment documentation without introducing a settings library yet.

```text
task-api/
  .python-version
  .gitignore
  .pre-commit-config.yaml
  .env.example
  pyproject.toml
  uv.lock
  README.md
  src/task_api/
    __init__.py
    domain/
    application/
    infrastructure/
  tests/
```

## Acceptance criteria

1. `uv sync --locked` succeeds from a clean checkout.
2. The package imports without adding the repository to `sys.path`.
3. Ruff format check and lint pass.
4. The selected type checker passes in strict mode with no blanket ignores.
5. pytest covers create, missing retrieval, completion, and pagination behavior.
6. `.env` is ignored and `.env.example` contains placeholders only.
7. README commands use uv consistently.

### Hints

Use `[tool.uv] package = true`, configure the build backend for the `src/task_api` package, and run every tool through `uv run`. Keep pre-commit fast; CI remains authoritative.

### Stretch goals

Add a console script that demonstrates the in-memory service, and a CI workflow that installs with `uv sync --locked` before running the exact documented checks.

<Solution>

A strong solution has one dependency source of truth and a small tool configuration:

```toml
[project]
name = "task-api"
version = "0.1.0"
requires-python = ">=3.13"
dependencies = []

[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"

[dependency-groups]
dev = ["mypy", "pre-commit", "pytest", "ruff"]

[tool.uv]
package = true

[tool.ruff]
target-version = "py313"
src = ["src"]

[tool.ruff.lint]
select = ["E", "F", "I", "UP", "B"]

[tool.mypy]
python_version = "3.13"
strict = true
```

The exact resolved versions belong in `uv.lock`. Verify the package from outside `src`, keep tests dependent on public behavior, and document one linear setup/check sequence. Module 4 will add Pydantic at the boundary; Module 5 will add FastAPI routes without reorganizing the domain core.
