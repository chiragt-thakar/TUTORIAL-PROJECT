## Translate errors at boundaries

Domain/application code raises meaningful exceptions such as `TaskNotFound` or `PermissionDenied`. FastAPI handlers translate them into one stable envelope:

```json
{"error":{"code":"task_not_found","message":"Task not found","request_id":"01J..."}}
```

Unexpected failures return a generic 500 message while logs retain the exception and stack trace. Never expose SQL, tokens, paths, or internal class names to clients.

Structured logs use named fields rather than interpolated prose:

```python
logger.info("task.created", extra={"task_id": task.id, "actor_id": actor.id})
```

A middleware accepts a valid incoming request ID or generates one, binds it to request context, returns it in a response header, and includes it in every log. Clear context after the request to prevent cross-request contamination.

## Production note

Log identifiers and outcomes, not passwords, tokens, full request bodies, or sensitive personal data. Define retention and access controls.

## Summary

Consistent translation and correlation make failures safe for clients and actionable for operators.
