## Health endpoints answer different questions

Liveness asks whether the process event loop can respond. Readiness asks whether this instance should receive traffic. A readiness check may perform a short database probe; liveness should not fail because a dependency briefly fails or a restart storm can result.

Use lifespan to create shared clients on startup and close them on shutdown:

```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    app.state.http = httpx.AsyncClient(timeout=3)
    yield
    await app.state.http.aclose()
```

Graceful shutdown stops new work, allows bounded in-flight work to finish, and closes pools. Background work that must survive process exit belongs in a durable queue, not an in-process task.

## Security baseline

Validate hosts and origins, set appropriate security headers at the edge/application, cap body and upload sizes, rate-limit expensive or credential endpoints, and pin/scan dependencies. Rate limiting supplements authentication; it does not replace it.

## Production note

Readiness probes need strict timeouts and shallow checks. A deep dependency tour can overload an already failing system.
