## Context managers define lifecycles

The `with` statement calls `__enter__`, runs the block, then calls `__exit__` even when the block raises. Files, locks, database transactions, and test patches use this protocol because acquisition and release remain adjacent.

```python
from contextlib import contextmanager

@contextmanager
def transaction(connection):
    try:
        yield connection
    except Exception:
        connection.rollback()
        raise
    else:
        connection.commit()
```

A generator-based context manager must yield exactly once. Never swallow an exception unless the context manager genuinely handled it. Async resources use `async with` and `@asynccontextmanager`.

<TypeScriptComparison>

JavaScript commonly uses `try/finally` and has newer explicit-resource-management syntax. Python's context-manager protocol is established across the ecosystem; SQLAlchemy sessions and FastAPI yield dependencies build on the same lifecycle idea.

</TypeScriptComparison>

## Dunder methods are protocols

Double-underscore methods let objects participate in language operations: `__repr__` for diagnostic representation, `__eq__` and `__hash__` for equality and hashed collections, `__len__` and `__iter__` for containers, and `__enter__`/`__exit__` for contexts. Implement them to express a real semantic contract, not to make syntax clever.

```python
from dataclasses import dataclass

@dataclass(frozen=True, slots=True)
class TaskId:
    value: str

    def __str__(self) -> str:
        return self.value
```

The dataclass generates useful `__init__`, `__repr__`, and equality behavior. `frozen=True` prevents ordinary reassignment and enables hashing when fields are hashable. `slots=True` prevents accidental attributes and can reduce per-instance overhead.

## Standard-library defaults

Use `pathlib.Path` instead of manual path separators. Use timezone-aware UTC datetimes. Use `Enum` or `StrEnum` for closed domain values, `uuid.UUID` for identifiers, `decimal.Decimal` for exact decimal amounts, `collections.abc` for interface annotations, and `secrets` rather than `random` for security tokens.

```python
from datetime import UTC, datetime
from enum import StrEnum
from pathlib import Path

class TaskStatus(StrEnum):
    OPEN = "open"
    DONE = "done"

created_at = datetime.now(UTC)
config_path = Path("config") / "local.toml"
```

<CommonMistake>

Naive datetimes do not say which instant they represent. Store aware UTC values, serialize them with offsets, and convert for display at the edge.

</CommonMistake>

<ProductionNote>

Prefer a well-known standard-library type to a home-grown helper. It lowers dependency count and makes behavior recognizable to every Python maintainer.

</ProductionNote>

## Exercises

<Exercise id="py-context-1">

Write a context manager that measures a block and always prints elapsed seconds, including when the block fails.

<Solution>

```python
from contextlib import contextmanager
from time import perf_counter

@contextmanager
def measured():
    started = perf_counter()
    try:
        yield
    finally:
        print(perf_counter() - started)
```

`finally` guarantees measurement; the exception continues outward.

</Solution>
</Exercise>

<Exercise id="py-context-2">

Model task priority as a string-valued enum with `low`, `normal`, and `high` wire values.

<Solution>

```python
from enum import StrEnum

class Priority(StrEnum):
    LOW = "low"
    NORMAL = "normal"
    HIGH = "high"
```

Members behave like strings while restricting the valid set.

</Solution>
</Exercise>

<Exercise id="py-context-3">

Replace `open(base + "/data/tasks.json")` with portable, automatically closed code.

<Solution>

```python
from pathlib import Path

path = Path(base) / "data" / "tasks.json"
with path.open(encoding="utf-8") as handle:
    payload = handle.read()
```

`Path` handles separators and `with` guarantees closure.

</Solution>
</Exercise>

You can recognize resource lifetimes as context-manager problems, choose dunder methods by protocol, and reach for standard-library types before adding dependencies.

</Checkpoint>

## Summary

Context managers make cleanup structural. Dunder methods connect objects to explicit Python protocols. The standard library already supplies strong primitives for paths, time, enums, identifiers, exact numbers, and secure randomness.
